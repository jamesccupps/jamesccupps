### Projects
📝 **[NoteForge](https://github.com/jamesccupps/NoteForge)** Encrypted offline note-taking with master-password and per-notebook locks. Electron + AES-256-GCM. Data stays local — no cloud, no account.

🐿️ **[Packet-Squirrel-Mark-II-Custom-Payloads](https://github.com/jamesccupps/Packet-Squirrel-Mark-II-Custom-Payloads)** 23 payloads for the Hak5 Packet Squirrel Mark II — packet capture, OT/ICS discovery, home-automation triggers, and more.

🏢 **[HVAC-Network-Scanner](https://github.com/jamesccupps/HVAC-Network-Scanner)** Multi-protocol BACnet scanner for commercial building automation networks. Raw UDP implementation, zero third-party dependencies, headless CLI and Tk GUI.

📡 **[PingerPlot](https://github.com/jamesccupps/PingerPlot)** Continuous-traceroute network path monitor for Windows (MTR-style). Per-hop latency, packet loss, jitter, and MOS with live latency graphs, alerts, and a world-map path view. Pure Python standard library — zero dependencies, no admin needed in ICMP mode.

🦈 **[P2_Wireshark_Dissector_and_P2_Scanner](https://github.com/jamesccupps/P2_Wireshark_Dissector)** Tools and a technical reference for P2 ("Protocol II"), the Siemens APOGEE building-automation protocol over TCP — for owner-operators working with their own legacy equipment.

🌡️ **[CoolingTowerSim](https://github.com/jamesccupps/CoolingTowerSim)** Physics-based browser simulator of a commercial building's condenser-water cooling loop. Animated process schematic, full tower-staging sequence of operations, and live power-draw KPIs. Single self-contained HTML file, calibrated against real BAS field trends — [live demo](https://jamesccupps.github.io/CoolingTowerSim/).

💧 **[Wetbulb](https://github.com/jamesccupps/Wetbulb)** Live, pressure-corrected wet-bulb temperature by ZIP, city, or GPS — the floor any cooling tower or evaporative process can chase. Iterative psychrometric solve at actual station pressure (not a sea-level fit), cross-checked against Stull (2011), plus a cooling-tower approach reference, shade-WBGT screening estimate, 24 h trend with next-24h forecast peak, and a fully offline manual calculator. Vanilla JS, zero dependencies, installable PWA — [live demo](https://jamesccupps.github.io/Wetbulb/).

📦 **[UnifiStockWatcher](https://github.com/jamesccupps/UnifiStockWatcher)** Restock alerter for the Ubiquiti Store. Python/tkinter with full-catalog monitoring and live stock-change alerts.
