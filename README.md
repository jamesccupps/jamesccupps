### Projects
🪨 **[Slate](https://github.com/jamesccupps/Slate)** A fast, simple Notepad replacement for Windows and Linux (Raspberry Pi included) that opens files of any size — an 800 MB JSON file opens instantly. Syntax colors for 52 languages, JSON and XML tools, tabs and unsaved changes that come back after a restart, automatic updates (signed exe on Windows, apt on Linux). Native Rust: Direct2D on Windows, GTK 4 on Linux — [download](https://github.com/jamesccupps/Slate/releases/latest).

📝 **[NoteForge](https://github.com/jamesccupps/NoteForge)** Encrypted offline note-taking with master-password and per-notebook locks. Electron + AES-256-GCM. Data stays local — no cloud, no account.

🐿️ **[Packet-Squirrel-Mark-II-Custom-Payloads](https://github.com/jamesccupps/Packet-Squirrel-Mark-II-Custom-Payloads)** 23 payloads for the Hak5 Packet Squirrel Mark II — packet capture, OT/ICS discovery, home-automation triggers, and more.

🏢 **[HVAC-Network-Scanner](https://github.com/jamesccupps/HVAC-Network-Scanner)** Multi-protocol BACnet scanner for commercial building automation networks. Raw UDP implementation, zero third-party dependencies, headless CLI and Tk GUI.

📡 **[PingerPlot](https://github.com/jamesccupps/PingerPlot)** Continuous-traceroute network path monitor for Windows (MTR-style). Per-hop latency, packet loss, jitter, and MOS with live latency graphs, alerts, and a world-map path view. Pure Python standard library — zero dependencies, no admin needed in ICMP mode.

🦈 **[P2_Wireshark_Dissector_and_P2_Scanner](https://github.com/jamesccupps/P2_Wireshark_Dissector)** Tools and a technical reference for P2 ("Protocol II"), the Siemens APOGEE building-automation protocol over TCP — for owner-operators working with their own legacy equipment.

⚙️ **[PPCL Workbench](https://github.com/jamesccupps/PPCL)** IDE, linter, simulator and debugger for Siemens PPCL — the line-numbered control language APOGEE and PXC field panels run. 90 lint rules, each citing the manual page it comes from; a browser IDE with a live point database; and an equipment bench that drives a program against a simulated air handler with sensor lag, actuator stroke time and injectable faults. Zero dependencies, Python stdlib only — nothing leaves the machine — [download](https://github.com/jamesccupps/PPCL/releases/latest).

🌡️ **[CoolingTowerSim](https://github.com/jamesccupps/CoolingTowerSim)** Physics-based browser simulator of a commercial building's condenser-water cooling loop. Animated process schematic, full tower-staging sequence of operations, and live power-draw KPIs. Single self-contained HTML file, calibrated against real BAS field trends — [live demo](https://jamesccupps.github.io/CoolingTowerSim/).

💧 **[Wetbulb](https://github.com/jamesccupps/Wetbulb)** Real-time, pressure-corrected wet-bulb temperature by ZIP, city, or GPS — with a cooling-tower approach reference, a shade-WBGT estimate, a 24-hour trend plus next-24h forecast peak, and a fully offline manual psychrometric calculator. — [live demo](https://jamesccupps.github.io/Wetbulb/).

📦 **[UnifiStockWatcher](https://github.com/jamesccupps/UnifiStockWatcher)** Restock alerter for the Ubiquiti Store. Python/tkinter with full-catalog monitoring and live stock-change alerts.

📹 **[Protect Panes](https://github.com/jamesccupps/UnifiCameraViewer)** UniFi Protect live view for Windows: each camera in its own borderless window you can place and size anywhere, or several in one grid window, across several consoles. Video comes over Protect's own livestream (no RTSP), with a local login (no cloud account or MFA). Also 360° fisheye dewarping, saved layouts with Protect liveview import, camera previews, and signed in-place updates. Electron — [website](https://jamesccupps.github.io/UnifiCameraViewer/) · [download](https://github.com/jamesccupps/UnifiCameraViewer/releases/latest).
