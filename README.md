### Building automation and HVAC

- 🏢 **[HVAC Network Scanner](https://github.com/jamesccupps/HVAC-Network-Scanner)**: finds and identifies building-automation devices (BACnet/IP and MS/TP, BACnet/SC, Modbus, KNX, LonWorks, Niagara Fox, OPC UA, APOGEE P2), reads points and flags factory-default logins. Read-only. [Website](https://jamesccupps.github.io/HVAC-Network-Scanner/) · [Download](https://github.com/jamesccupps/HVAC-Network-Scanner/releases/latest)
- 🦈 **[APOGEE P2 Toolkit](https://github.com/jamesccupps/P2_Wireshark_Dissector_And_P2_Scanner)**: Wireshark dissector, read-only scanner, virtual PXC panel and P2 → BACnet/IP bridge for Siemens APOGEE P2, plus a wire-level protocol reference. [Protocol reference](https://jamesccupps.github.io/p2/) · [Releases](https://github.com/jamesccupps/P2_Wireshark_Dissector_And_P2_Scanner/releases/latest)
- ⚙️ **[PPCL Workbench](https://github.com/jamesccupps/PPCL)**: IDE, linter, simulator and debugger for Siemens PPCL. 90 lint rules, each cited to the manual page it comes from, and a simulated air handler to run programs against. [Website](https://jamesccupps.github.io/PPCL/) · [Releases](https://github.com/jamesccupps/PPCL/releases/latest)
- 📈 **[HVACTrend](https://github.com/jamesccupps/HVACTrend)**: read-only BACnet/IP trend logger and web viewer. Logs the points you pick every two minutes and sends equipment alarms to your phone. [Website](https://jamesccupps.github.io/HVACTrend/) · [Releases](https://github.com/jamesccupps/HVACTrend/releases/latest)
- 🌡️ **[Cooling Tower Sim](https://github.com/jamesccupps/CoolingTowerSim)**: physics-based simulator of a condenser-water loop, with tower staging and live power draw, in one HTML file. [Live demo](https://jamesccupps.github.io/CoolingTowerSim/)
- 💧 **[Wet-Bulb Calculator](https://github.com/jamesccupps/Wetbulb)**: live, pressure-corrected wet-bulb by ZIP, city or GPS, with a cooling-tower approach reference and shade WBGT. [Live demo](https://jamesccupps.github.io/Wetbulb/)
- 🧮 **[AllCalc](https://play.google.com/store/apps/details?id=com.hvaccalc)**: offline Android field calculator with 80+ tools for HVAC, electrical and plumbing work. [Google Play](https://play.google.com/store/apps/details?id=com.hvaccalc)
